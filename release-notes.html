FiltaQuilla 6.3.2 Important for Release channel users (154 and later): With Thunderbird's new 2-week release cycle, there is an elevated risk of unexpected breakages. While I regularly test FiltaQuilla against daily builds, timely fixes depend on early reporting from Release users. Please follow the issue tracker and report any regressions promptly to help maintain compatibility. Additional regressions are expected within the Thunderbird release branch and will be addressed as they occur. Users who rely on advanced or experimental functionality may prefer the ESR channel for a more stable environment with fewer platform changes. Changes in 6.3.2
  • Made FiltaQuilla compatible with Thunderbird 160.*.
  • Fixed save completion errors on Thunderbird 159 beta caused by the removal of msgHdrFromURI, which could also delay subsequent move actions. [issue 421]
  • Fixed JavaScript editor failing to open when the calculated popup height was not an integer. [issue 419]
Recent History: 6.3.1
  • Made FiltaQuilla compatible with Thunderbird 159.*.
  • Improved startup reliability by allowing more time for Thunderbird windows to finish loading.
  • Fixed errors in the Save Message as File filter action caused by a changed Thunderbird API. [issue 417]
Planned Next
  • Restore the “Folder Name” search term on newer Thunderbird versions. [issue 377]
  • Support custom filenames when saving or detaching attachments. [issue 219]
  • Review attachRegEx_match for current Thunderbird versions.
