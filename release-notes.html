This release updates FiltaQuilla to reflect recent changes in Thunderbird’s add-on platform planning. The planned restriction on the use of Experiment APIs on the Release channel has been postponed and is now scheduled for the following ESR cycle in 2027. With Thunderbird 153 ESR arriving in July, a transition window opens during which users can switch from Thunderbird 153 Release to the ESR channel to secure a more stable update path. From the following ESR cycle in 2027 onwards, legacy add-ons will only be supported on ESR versions. Users who rely on advanced or experimental functionality may prefer the ESR channel for a more stable environment with fewer platform changes. The recommended migration point from Release to ESR is Thunderbird 153, expected in July 2026. If you would like to support FiltaQuilla with donation you can now do so here. For more ways of supporting me work, please read the section below after the change log. Improvements
  • Made FiltaQuilla compatible with Thunderbird 153.*. We are ready for the next ESR cycle!
  • Prepend / Append Date to subject [issue 398] Added %date()% switch for subject prefix / append, for a list of letters you can use in the format string - See: https://smarttemplates.quickfolders.org/variables.html#customDates Example: Prefix Subject: `%date("Y-m-d")% [Important]
  • Added tool tip to regular expression option for case insensitive matching
  • Made regex options panel theme compatible
  • JavaScript search term now forces needsBody = true for stability [issue 403]. This may potentially lead to slow down but it is necessary for searches that may require parts of the message to be downloaded - in which case the search term needs to "know" it. This can be disabled in settings (advanced users only).
Bug Fixes
  • Fixed regex pseudo-flag "c" - which forces case sensitive behavior overriding "Regex case-insensitive Match"
  • Header regex: headers like "in-reply-to" are not exposed and do not work [issue 395]. You can now search for headers that are not part of the message database, which can be enabled with a separate settings. This requires streaming part of the message and may lead to slowdown during filtering - therefore we recommend it only in filters that run manually.
Planned Next

  • Custom filenames when saving attachments. [issue 219]
