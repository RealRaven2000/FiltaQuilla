We decided to concentrate on the latest versions from Thunderbird v140 onward because the code base was getting pretty unmanageable due to the substantial changes in Thunderbird Core and additional features added by the extended mail extension APIs. Being able to support this and legacy ways of doing the same thing within the same Add-on proved to be very difficult and produce unmanageable code. Even just supporting both ESR140 and the current release versions (currently 147), is already a difficult thing leading to substantially branching code paths within the same Add-on. This cut-off point will also be used to prepare for a number of long desired feature additions around saving attachments, which will be delivered next. Increased strict_min_version to 140.0.
