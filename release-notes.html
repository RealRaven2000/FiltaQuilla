This release updates FiltaQuilla to reflect recent changes in Thunderbird’s add-on platform planning. A previously announced restriction affecting Experiment APIs on the Release channel has been postponed to a later ESR cycle (currently targeted for 2027). No immediate action is required. FiltaQuilla continues to work on both Release and ESR versions of Thunderbird where supported. Users who rely on advanced or experimental functionality may prefer the ESR channel for a more stable environment with fewer platform changes. The recommended migration point from Release to ESR is Thunderbird 153, expected in July 2026. If you would like to support FiltaQuilla with donation you can now do so here.
